Seat View Animations

Two "see the view before you pay" prototypes. Plain HTML, CSS and canvas, no build step.

Window view · BR 214

Tap a window seat on the plane map and scrub the flight from Barcelona to Paris. Try row 11 for the "no window" surprise.

View from seat · Meridian
